Fluxer World

A community instance powered by the Fluxer platform.

Fluxer World is an independent public community built on the open-source Fluxer platform. It provides chat communities, voice channels, and an open ecosystem where anyone can participate or host their own server.

Fluxer World is not the official Fluxer instance.

About

What is Fluxer?

Fluxer World runs on Fluxer, an open-source communication platform. Unlike centralized chat platforms, Fluxer allows anyone to run their own server and build their own communities.

Fluxer World exists to support and grow this ecosystem.

  • Community servers
  • Text chat
  • Voice channels
  • Customizable clients
  • Self-hosting capabilities
Mission

Why Fluxer World exists

Fluxer World was created to help build a strong public home for Fluxer communities.

Open platforms

Support open communication platforms that respect users and communities.

Lower the barrier

Make self-hosting easier and more accessible for new users getting started with Fluxer.

Polished tools

Provide stable, well-maintained clients and tools that make using Fluxer reliable and enjoyable.

Grow the ecosystem

Help improve the Fluxer platform through contributions, testing, and community feedback.

Community first

Keep the platform community-driven and independent from corporate control.

Open development

Build transparently with open-source code, public issue tracking, and community input.

Features

What Fluxer World provides

End-to-End Encrypted

Direct messages — both 1:1 and group — and 1:1 voice/video calls are end-to-end encrypted. Not even the server can read them.

Open Source

Fluxer and many tools around it are open source and community driven.

Self-Hosted

Anyone can run their own Fluxer server and maintain full control over their data.

Polished Clients

Stable and well-maintained desktop and mobile clients for everyday use.

Community Driven

Built for communities and collaboration rather than corporate control.
