Get the clients

Fluxer World provides clients for multiple platforms. Available on the Snap Store, AUR, Copr, F-Droid, GitHub Releases, and more.

Snap Store AUR Fedora Copr F-Droid AppImage
Install via terminal
Snap: sudo snap install fluxer-world
Arch (AUR): yay -S fluxer-world-bin
Fedora (Copr): sudo dnf copr enable xuruh/fluxer-world && sudo dnf install fluxer-world
F-Droid: Add repo https://fluxer.world/fdroid/repo in F-Droid settings
